# Agent Rules & Guidelines

## Git Operations
- **Strictly no automated commits**: Do NOT run `git commit`, `git commit -a`, or `git push` without explicit user permission/approval in the chat.
- Always leave code edits as uncommitted changes in the working tree so the user can review them first.
- Only create a git commit if the user explicitly asks to commit (e.g., "commit these changes", "make a commit").
